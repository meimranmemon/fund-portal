# Fund Investor Portal - Migration Folder

Is folder mein poora code hai (lib, api, migrations, login, theme).

KAMI: `public/index.html` is zip mein nahi hai. Usay apni live app se Ctrl+S karke
"index.html" naam se save karein aur `public/` folder mein rakh dein (ya Claude se maangein).

## Antigravity mein kaise use karein
1. antigravity.google se Antigravity install karein, Gmail se sign in.
2. File > Open Folder > is folder (zip extract karke) ko kholein.
3. `ANTIGRAVITY_PROMPT.md` kholein, poora text copy karke Antigravity ke agent chat mein paste karein.
4. Jo woh bole woh karein. Passwords / keys chat mein na bhejein, `.env` file mein khud likhein.
